# Hand texture

The hand atlas uses the CC0 male skin by jartur69 distributed in [MakeHuman skins02](https://static.makehumancommunity.org/assets/assetpacks/skins02.html). The embedded GLB texture uses only the hands and wrists.

The source image is 2048 × 2048. Pixel rectangles use top-left coordinates with exclusive right and bottom edges. The hand islands at (734, 1638, 1569, 2032) start at (0, 0) in the 928 × 400 atlas. The wrist strips at (12, 279, 92, 431) and (1467, 279, 1546, 431) start at (840, 0) and (840, 160).
