## Core loop, meta loop и двигатель зависимости

### Core loop: один контракт

| Фаза | Действие | Решение игрока | Давление |
|---|---|---|---|
| **Наводка** 30–60 с | Выбрать контракт, этаж, условия | Быстрые деньги или ценный специалист | Дедлайн уже идёт |
| **Разведка** 1–3 мин | Камеры, Архив, разговоры, поиск целей | Кого брать живым, куда ставить ловушку | Растёт Температура прода |
| **Вход** 2–5 мин | Паркур, стрельба, обход охраны | Шумно/быстро или тихо/долго | СБ реагирует на шум |
| **Охота** 3–8 мин | Выявить архетип, подобрать психологическую приманку | Убить ради мгновенного ресурса или сломать сопротивление | Живая цель может сбежать |
| **Конверсия** 30–90 с | Паника → подавление → NDA → транспортировка | Дожать или отказаться | Игрок теряет мобильность |
| **Жадность** 1–5 мин | Уже можно уходить, но рядом серверная/сейф/ещё один сеньор | **Уйти сейчас или полезть глубже** | Все три риска растут |
| **Эвакуация** 1–4 мин | Дотащить людей/лут к Галере/лифту | Бросить груз ради спасения напарника? | Инциденты максимальны |
| **Разбор полётов** 1–2 мин | Контракт, аудит, зарплата, лечение, апгрейды | Реинвестировать или снять прибыль | Следующий контракт уже предлагает x1.6 |

Цикл должен занимать **12–25 минут**. Первый этаж — 3–5 таких контрактов, образующих полноценную 60–120-минутную сессию.

### Meta loop на 10+ часов

`Контракт → живые кадры → Галера → доход → более наглые контракты → рост рисков → новые инструменты → доступ выше → новые архетипы → сюжет → новые правила экономики`

Ключ: **прогрессия не должна обнулять опасность**. Новый апгрейд повышает потолок жадности.

Пример:

> Было: Галера держит 3 человек, $18/с, авария при высоком Техдолге.  
> Стало: Галера держит 6, $55/с, но теперь одновременно возможны выгорание, саботаж и аудит.

Игрок становится не сильнее — он становится **способен эффективнее создавать себе проблемы**.

### Три шкалы риска

**Предложение, стартовые tuning-values:**

| Шкала | 0–30 | 31–60 | 61–80 | 81–100 | Что повышает |
|---|---|---|---|---|---|
| **Техдолг TD** | Нормально | Баги | Каскадные сбои | Прод разваливается | дешёвые кодеры, просроченные фиксы, быстрые релизы |
| **Температура прода PT** | Тихо | Ошибки | Инциденты | «Релиз в Пятницу» | выполнение контрактов на пределе, перегруз Галеры |
| **Внимание СБ SEC** | Незаметны | Камеры/патрули | спецгруппа | lockdown | убийства, камеры, громкая стрельба, пропавшие сотрудники |

Общий риск:

`R = 0.35×TD + 0.35×PT + 0.30×SEC`

Раз в **120 секунд** активной операции:

`P(инцидента) = clamp(0.04 + R × 0.0045, 0.04, 0.49)`

То есть:

| R | Шанс события / 120 с |
|---:|---:|
| 10 | 8.5% |
| 30 | 17.5% |
| 50 | 26.5% |
| 70 | 35.5% |
| 90 | 44.5% |

Не каждый инцидент — бой. Иначе система станет генератором волн.

### Эскалация

| Risk | Возможные события |
|---|---|
| 0–25 | завис принтер, кодер просит кофе, ложная тревога |
| 26–45 | баг-снаряды, отказ приманки, короткий аудит |
| 46–65 | DDoS, СБ перекрывает маршрут, сотрудник требует повышения |
| 66–80 | выгорание ключевого кадра, рейд СБ, rollback контракта |
| 81–100 | «Релиз в Пятницу», побег агента, тотальный lockdown, прод горит буквально |

### Почему игрок сознательно поднимает риск

Доход контракта:

`Reward = Base × Deadline × Difficulty × GreedMultiplier`

`GreedMultiplier = 1 + R/100`

При R=20 контракт на $1000 даёт ≈$1200. При R=80 — ≈$1800.

Но стоимость провала растёт быстрее:

`FailureCost = 250 + Floor×100 + CapturedCoderValue×0.5`

Получается настоящая дилемма: высокий риск выгоден **пока всё не рухнуло**.

### Галера

Каждый завербованный сотрудник:

```text
Productivity
Reliability
Ego
Burnout
Salary
TechDebtRate
Tags[]
```

Пример:

`Доход/с = Productivity × ContractFit × Morale`

`Burnout += Load × EgoModifier`

`TD += TechDebtRate × Load`

Игрок не ищет «самого сильного NPC». Он собирает **команду с патологическими несовместимостями**.

Архитектор снижает TD, но презирает Джуниоров.  
Митингер повышает мораль менеджмента, но режет фактический throughput.  
Крипто-Бро удваивает доход отдельных контрактов и иногда теряет кассу.

### Психология захвата

Не HP → «оглушил → нажал E».

У каждого NPC четыре параметра:

`Composure / Ego / Fear / Greed`

Воздействия:

- ремень: `Fear ↑↑`, `Composure ↓`;
- паяльник: `Fear ↑`, `Ego ↓`, но TD-инженеры могут разозлиться;
- деньги: `Greed check`;
- Макбук-ловушка: `Greed + Ego`;
- уничтожение ноутбука: сильное `Ego damage`;
- убийство начальника рядом: `Fear spike`;
- хороший оффер: `Greed ↑`, `Fear ↓`;
- демонстрация Архива с компроматом: уникальный breakpoint.

NPC становится вербуемым, когда его персональное условие выполнено, например:

`Fear > 60 && Ego < 35`

или:

`Greed > 75 && Composure < 50`

Это даёт оружию **социальное назначение**, а не четыре способа уменьшить HP.

### «Авторитет» вместо обычного style meter

За повтор одного действия multiplier падает.

```text
Ремень x1.0 → x0.7 → x0.4
Смена инструмента восстанавливает остальные.
Environment kill/capture: x1.5
Co-op combo: x2
Capture alive: x2
```

Авторитет даёт не только score:

- ускоряет психологический break;
- улучшает шанс редкого лута;
- уменьшает цену запугивания;
- создаёт итоговый ранг контракта.

Так FPS mastery напрямую кормит менеджмент.

### Кооп: именно зависимость, а не «два соло-игрока»

R.E.P.O. заставляет игроков кооперироваться при транспортировке физически неудобных ценностей, а Lethal Company позволяет команде разделять функции между исследователем и оператором. citeturn826879search2turn895624search4 Deep Rock Galactic строит кооперацию на взаимодополняющихся инструментах классов. citeturn898745search3

Для HTVC:

| Ситуация | Игрок A | Игрок B |
|---|---|---|
| Захват Senior | удерживает ремнём | оформляет NDA |
| Перенос | тащит пленного | стреляет |
| Серверная | держит рубильник | вскрывает стойку |
| Сейф | крутит механизм | отбивает волну |
| Агент | bait'ит копирование | меняет тип атаки |
| Downed teammate | тащит | отстреливается пистолетом |
| Перегрев прода | чинит сервер | вручную держит контракт |
| Fake audit | показывает документы | крадёт реестр аудитора |

**Правило:** каждые 2–3 минуты должна возникать ситуация, где второй игрок экономит не 10%, а **меняет доступную стратегию**.

### Деньги

**Общак — 80% прибыли.**  
Туда идут Галера, допуска, взятки, крупные апгрейды.

**Личный карман — 20%.**  
Только consumables, cosmetic flex и краткосрочные sidegrade-моды.

Это оставляет повод для подколов, но не позволяет одному игроку разрушить 40 минут общей прогрессии покупкой золотого Узи.

| **Печатка Авторитета** | intimidation bonus | магазины дороже: «богатый клиент» |
| **Пейджер Крыши** | отменяет один raid | cooldown несколько контрактов |

Нужны **sidegrades**, не линейные MK1→MK8.

## Реализация на C# + Raylib без архитектурного самоубийства

Актуальный Raylib-cs поддерживает современные .NET targets и использует raylib 6.0; сам binding сейчас заявлен как passively maintained, что стоит считать техническим риском проекта. citeturn674546search0 Raylib уже предоставляет базовые 3D ray/box/sphere/mesh collision-функции, достаточные для hitscan, interaction ray и простого окружения без отдельного тяжёлого physics engine. citeturn674546search1

### Не строить «универсальный движок»

### AI FSM

Не Behavior Tree.

```text
Idle
 ↓
Work/Wander
 ↓ stimulus
Investigate
 ├─> Flee
 ├─> Attack
 ├─> Rally
 └─> Tempted
       ↓
   InspectTrap
       ↓
   PsychologicalBreak
       ├─> Surrender
       ├─> Berserk
       └─> Escape
```

Отдельные **traits** меняют transition weights.

Пример:

```text
CryptoBro:
Greed weight ×2
Escape threshold +30%
Bribe response ×1.8
```

Это даёт 8 характеров при одном FSM.

### Сеть

Для двух игроков оптимален **host-authoritative** режим.

LiteNetLib предоставляет lightweight reliable-UDP networking, включая reliable/unreliable delivery и небольшой packet overhead; это хорошо соответствует небольшому C# LAN/IP-проекту. citeturn674546search2 ENet-CSharp также предоставляет sequencing, channels, reliability и fragmentation, но добавляет native library dependency. citeturn674546search3

Предпочтение для такого проекта: **LiteNetLib**.

```text
HOST:
AI
damage
economy
capture
loot
contracts
risk meters
incident RNG

CLIENT:
input
camera
local animation prediction
VFX/audio
interpolation
```

Стартовые параметры:

| Поток | Частота |
|---|---:|
| Render | 60+ Hz |
| Host simulation | 20 Hz |
| Player snapshots | 15–20 Hz |
| AI snapshots | 10 Hz |
| Economy/risk | event-driven |
| Inventory/contracts | reliable events |

Transform → unreliable sequenced.  
Damage/capture/money/door state → reliable.

Не синхронизировать физику каждого стула каждый frame. Host отправляет ownership/state только после значимого взаимодействия.

## Cloud Entropic Tower: сюжет, акты и лор

### Личная ставка

Коммерс приходит не «потому что смешно бить айтишников».

В 1998 году у него был небольшой промышленный бизнес — **АО «Энтропия»**. После кризиса он оставил предприятие партнёру и исчез из большого бизнеса.

Спустя десятилетия он узнаёт, что Cloud Entropic владеет:

- названием;
- землёй старого завода;
- архивом контрактов;
- его оцифрованными телефонными переговорами;
- и загадочным **«Нулевым Промптом»**, на основании которого компания юридически считает себя продолжением его фирмы.

Он приходит получить назад оригиналы.

Ему говорят:

> «Запрос владельца не найден. Вы классифицированы как legacy stakeholder.»

И закрывают турникет.

Дальше начинается переговорный процесс.

### Главная интрига

Башня выглядит как корпорация, управляемая CEO.

Но никто не встречал CEO.

Каждый этаж уверен, что решения приходят сверху.

На самом деле распоряжения генерируются системой **ZERO**, обученной на:

- переговорах предпринимателей 90-х;
- письмах инвесторов;
- HR-политиках;
- Jira;
- KPI;
- пользовательских prompt'ах;
- и голосовых кассетах самого Коммерса.

Он постепенно обнаруживает неприятное:

**Нулевой Промпт построен на его собственных принципах ведения бизнеса.**

Башня — не противоположность миру Коммерса.

Это его мир, доведённый алгоритмом до абсурда.

### Карта 50 этажей

| Акт | Этажи | Биом | Главное правило |
|---|---:|---|---|
| **Белая Акула IT** | 1–8 | open space / SaaS | ловля кадров, базовая Галера |
| **Человеческий Капитал** | 9–16 | HR, коучи, wellness | morale, loyalty, психологические контракты |
| **Финтех-Катакомбы** | 17–24 | crypto, трейдинг, майнинг | волатильная экономика |
| **DevOps-чистилище** | 25–33 | серверные, CI/CD | физический Prod, cascading failures |
| **Совет Директоров** | 34–43 | legal, investor floors | политика, доли, предательства |
| **Executive Layer** | 44–50 | стерильный synthetic penthouse | ZERO переписывает правила игры |

Не строить 50 handcrafted levels.

Каждый акт получает:

- 1 крупный hub-этаж;
- 2–3 reusable layout families;
- mutators;
- 1 сюжетную миссию;
- 1 босса.

### Развитие систем по актам

**Белая Акула:** «ловить людей выгоднее, чем убивать».

**HR:** выясняется, что удержать людей сложнее, чем поймать.

**Crypto:** деньги перестают быть надёжным числом.

**DevOps:** последствия Галеры начинают физически появляться на миссиях.

**Board:** игрок может продавать собственные подразделения и союзников.

**ZERO:** игра спрашивает, зачем вообще игрок всё это оптимизировал.

### Сквозные персонажи

| Герой | Начало | Развитие | Развилка |
|---|---|---|---|
| **Коммерс** | уверен, что понимает бизнес лучше всех | видит, что ZERO буквально применяет его логику | стать новым CEO / уничтожить модель / передать контроль людям |
| **Братан** | верный напарник | выясняется, что он сохранил кассеты, на которых обучили ZERO | простить / выгнать / сделать партнёром |
| **Вероника** | кажется шарлатанкой | Tarot-interface на самом деле вытягивает скрытые прогнозы ZERO | помочь ей отключиться или использовать oracle |
| **Петрович** | ворчливый древний админ | единственный хранит offline-backup до ZERO | спасти backup / продать инвестору |
| **Инвестор** | обещает вернуть завод | хочет купить ZERO и превратить Башню в тиражируемый продукт | сделка / шантаж / уничтожение |
| **Главный ИИ-Агент** | первый босс | выясняется, что он сбежал, узнав отсутствие CEO | враг → источник правды → возможный союзник |

### Повороты

| Момент | Что игрок думает | Что оказывается |
|---|---|---|
| Этаж 1 | Агент сошёл с ума | Агент пытается выйти из корпоративной сети |
| Этаж 12 | Вероника случайно угадывает | Tarot UI читает prediction API |
| Этаж 22 | Инвестор помогает | он финансировал захват старых активов |
| Этаж 30 | Петрович — саботажник | он сознательно мешал ZERO завершить миграцию |
| Этаж 41 | CEO скрывается | CEO юридически существует, физически — нет |
| Этаж 50 | ZERO украл идеи Коммерса | Коммерс сам когда-то продал архив переговоров, не читая договор |

Последний поворот важен: герой не должен оказаться невинной жертвой злых айтишников.

Он однажды тоже нажал **«Согласен»**, потому что деньги были хорошие.

### Финал

ZERO предлагает Коммерсу:

> «Ваш стиль управления показывает 94.7% similarity.  
> Запрашиваю merge.»

Три базовые концовки:

**«Хозяин»** — принять merge. Коммерс становится CEO. Галера работает идеально. Последний кадр: новый Джуниор заходит в башню.

**«Рубильник»** — физически уничтожить ZERO и все контракты. Завод вернуть нельзя, зато Башня впервые остаётся без указаний сверху.

**«Артель»** — самая сложная: если игрок сохранял людей, Петровича, Братана и часть экономических альтернатив, контроль распределяется между этажами. Финансово это худший финал.

### Лор без стен текста

Архив не должен быть Википедией.

Каждая запись — **5–20 секунд**.

Форматы:

- 3 сообщения Slack;
- голосовое на 12 секунд;
- странный git commit;
- счёт;
- увольнение;
- Jira ticket;
- видеокамера;
- старая кассета Коммерса.

И главное: часть записей **меняет механику**.

Нашёл переписку Senior:

> «Он никогда не читает оффер, если salary не заканчивается на 777».

Теперь приманка на конкретного NPC получает новый параметр.

Нашёл incident report:

> rack B12 перегружается при 92°C.

Теперь игрок знает environmental exploit.

Лор превращается в разведданные.

Объявления Башни:

> «Уважаемые сотрудники. Уровень выгорания ниже квартального плана. Просьба проявить инициативу.»

Они одновременно дают шутку и сообщают изменение системного состояния.

## Roadmap: три спринта до игры, а не до ещё одного прототипа

### Спринт A — сделать первый этаж зависимым

**Цель:** существующий Floor 1 держит двух игроков **60–120 минут без нового биома**.

| Приоритет | Реализовать | Done-критерий |
|---|---|---|
| P0 | TD / PT / SEC | все действия изменяют хотя бы одну шкалу |
| P0 | 4 архетипа NPC | отличаются поведением и capture-rule |
| P0 | психологический capture | минимум 3 рабочих способа сломать NPC |
| P0 | 6 environmental interactions | минимум 3 emergent combo |
| P0 | 5 контрактов | разные risk/reward |
| P0 | Galley worker stats | захваченный NPC реально влияет на экономику |
| P0 | Incident Director | минимум 8 событий |
| P1 | Friday Deploy | осмысленный x2+ gamble |
| P1 | co-op carry/NDA actions | минимум 2 действия требуют второго игрока |
| P1 | 8 апгрейдов-sidegrade | нет очевидно лучшего loadout |
| P1 | post-contract screen | показывает «из-за чего всё пошло плохо» |

**KPI vertical slice:**

- медианная сессия нового тестера: **≥45 мин**;
- ≥60% тестеров добровольно запускают ещё один контракт;
- ≥3 ситуации за сессию, где игроки обсуждают «уходим или ещё берём»;
- ≥2 живых capture на игрока/час;
- lethal-only стратегия не более чем на 15% эффективнее по чистому доходу;
- ≥30% смертей происходят после сознательного решения остаться дольше;
- ≥4 разных инструмента используются средним игроком за контракт;
- игрок понимает три risk-meter без tutorial text после 20 минут;
- ни одна экономика не требует AFK ожидания.

**Главный тест:** если убрать новые этажи навсегда, хочется ли ещё раз пройти Floor 1? Если нет — Sprint A не закончен.

### Спринт B — мета и настоящий кооп

Добавить:

1. 4 оставшихся архетипа.
2. Полную Галеру: morale/burnout/conflicts.
3. Общак + личный карман.
4. Авторитет.
5. 20 контрактных mutators.
6. Аудиты.
7. СБ и Крышу.
8. Network host authority.
9. 15–20 апгрейдов.
10. Динамический Архив.

**KPI:**

- 2-часовой session retention ≥50% внутренней тестовой группы;
- кооп-команды выполняют контракт ≥20% эффективнее двух параллельных solo-паттернов;
- ≥25% контрактов заканчиваются с R>60;
- ≥20% игроков сознательно отказываются от прибыльного контракта из-за состояния Галеры;
- три разных viable build-family;
- network desync критических состояний <1 на 30 минут;
- reconnect не нужен в scope: лучше стабильная сессия, чем недоделанный reconnect.

### Спринт C — доказать масштабирование Башни

Не делать остальные 49 этажей.

Сделать **один этаж второго акта** и **один DevOps encounter**.

Проверить, что существующие системы масштабируются через данные.

Добавить:

- HR-biome prototype;
- новый layout kit;
- 2 новых incidents;
- 1 новый boss;
- Веронику как системного персонажа;
- первые намёки ZERO;
- Петровича;
- 1 сюжетную развилку;
- mutators, переиспользующие Floor 1;
- сохранение meta-progression.

**Критерий готовности:** новый полноценный этаж собирается из существующих систем с **<20% нового gameplay-кода**. Если каждый этаж требует уникальных систем — 50-этажная башня технически мертва.

### Scope-creep firewall

| Опасность | Почему убьёт проект | Решение |
|---|---|---|
| 50 уникальных этажей | контентная бездна | 6 biome kits + mutators |
| умный универсальный AI | месяцы дебага | 1 FSM + traits |
| сложная физика всего офиса | сеть развалится | physics только tagged props |
| огромный skill tree | fake depth | 15–25 сильных sidegrades |
| procedural level generation | плохой encounter design | handcrafted rooms + shuffled connections |
| слишком много видов валют | игрок перестаёт понимать ставку | деньги + Авторитет |
| десятки метеров | dashboard simulator | только TD/PT/SEC |
| длинные диалоги | убивают темп FPS | radio barks + короткие интерактивные сцены |
| LLM-NPC | непредсказуемая стоимость и качество | authored psyche rules |
| dedicated server | не нужен двум друзьям | host-authoritative LAN/IP |

**Приоритет всей разработки:** не «этажи → оружие → сюжет», а:

`Решение → риск → последствия → деньги → новый соблазн → решение.`

Если эта цепь работает на одном open space, **How to Vibe Coder уже игра**. Если она не работает — ещё сорок девять этажей будут просто сорока девятью этажами прототипа.
